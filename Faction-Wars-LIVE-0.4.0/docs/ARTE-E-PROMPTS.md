# Artes da atualização local 0.4.1

Geradas com a ferramenta integrada `image_gen`, usando como referências as duas imagens fornecidas pelo proprietário e a arena anterior. Não foi usada API paga por chave local ou CLI. Os arquivos originais gerados foram preservados e copiados para o projeto.

- `src/ui/assets/arena-approved-v1.png`: 941 × 1672, RGB. Cenário sem HUD ou tropas; exibido na área útil da arena vertical.
- `src/ui/assets/troops-approved-v1.png`: 1254 × 1254, RGBA com transparência. Atlas 4 × 4 com Guerreiro, Defensor, Arqueiro e Cerco; Safira/Rubra, frente/costas.
- `src/ui/approved-sprites.js`: usa o atlas no runtime para compor 32 frames por classe/facção. Nenhum resultado de combate vem da imagem.
- `src/ui/assets/approved-manifest.json`: dimensões e hashes dos assets.

Os prompts pediram tamanhos maiores; as dimensões acima são as efetivamente retornadas. O jogo calcula as células a partir do tamanho real do atlas.

## Prompt final da arena

Use case: stylized-concept. Asset type: production background environment for an existing functional vertical 9:16 medieval battle game, NOT a screenshot or mockup. Generate one richly detailed polished stylized 3D medieval arena environment in portrait 9:16, ideally 1080x1920. Reference image 1 is the art-quality/style direction: beautiful beveled pale sandstone, blue and red banners, gold crystal pedestals, lush vines, torchlight, miniature fantasy diorama quality. Reference image 2 has rough annotations showing ONE central nexus per faction and open shared courtyards. Reference image 3 is the existing simple low-poly environment whose precise game layout MUST be retained while improving art to match reference 1. Composition invariant: THREE straight parallel walkable stone lanes run vertically. Lane centerlines at 27%, 50%, 73% of image width. Two narrow leafy divider walls at 38.5% and 61.5% of width extend only from y=29% to y=70%, stopping well before each nexus to open both shared courtyards. Exactly ONE blue faceted crystal nexus centered at x=50%, y=18% and exactly ONE red faceted crystal nexus centered x=50%, y=81%, each on an ornate low round gold and stone pedestal. No additional crystals anywhere. Open unobstructed paving on left/right/center approaches to each crystal. Outer perimeter stone ramparts, dense green vegetation, restrained blue/red pennants, warm torches and dark blue water around the arena. Consistent near-orthographic elevated camera, symmetrical readable game-board layout, sunlight from upper left, detailed ambient occlusion. Keep the three lane paving paths clean and unobstructed. Center at y=50% each lane has EMPTY paving where the real engine draws capture circles, do not bake circles in. CRITICAL: No characters, soldiers, units, cannons, troops, silhouettes, health bars, objective markers, circles, interface, cards, labels, text, typography, numbers, title, logos, HUD or watermark. The live game renders all gameplay and HUD above this asset. Fill entire portrait with environment; no blank border. Artwork original inspired by provided user-owned references. Rich sculpted stones and high quality materials, no simplistic flat low-poly trees.

## Prompt final das tropas

Use case: stylized-concept. Asset type: actual transparent game sprite atlas, not concept sheet. Create a square 2048x2048 transparent PNG arranged in an EXACT, evenly spaced 4 COLUMN x 4 ROW grid, 16 isolated original highly polished stylized 3D medieval game units. No grid lines and NO TEXT. Input reference image is ONLY art-quality/style reference for cute detailed metallic armored soldiers with vivid team colors and robust cannons. Exact logical cells: 512x512 each; keep every unit fully contained in central 74% of its own cell, centered horizontally, soles/wheels aligned at 84% of cell height. Same camera across all: slightly elevated orthographic game camera, three-quarter facing SOUTH means toward viewer, NORTH means back facing viewer, actual figure arms and weapons fully visible. COLUMN 1: sword warrior with steel helmet, plate armor, sword in right hand, small heraldic shield. COLUMN 2: bulky armored defender with very large ornate kite shield, broad silhouette. COLUMN 3: medieval archer with hood/helmet, bow in hand and quiver, visibly distinct from melee. COLUMN 4: sturdy heavy wheeled siege cannon with gold-edged steel barrel and large wheels, no soldier operating it. ROW 1: ALL FOUR BLUE/SAPPHIRE team units FACING SOUTH toward viewer. ROW 2: SAME FOUR BLUE/SAPPHIRE units FACING NORTH, viewed from behind. ROW 3: ALL FOUR RED/RUBY team units FACING SOUTH toward viewer. ROW 4: SAME FOUR RED/RUBY units FACING NORTH viewed from behind. The cannons aim in the same north/south direction as their row. Consistent unit identity between front and back, warm gold trim, rich blue/red cloth, detailed steel, readable 3D volume, crisp silhouette, beautiful fantasy miniature render matching reference. Characters neutral combat-ready stance. Grid alignment is critical for automatic cropping in the game engine. All 16 must appear once, no additional figures, no missing cells, no objects crossing cell boundaries. Genuine transparent background, no floor, no drop shadows, no labels, no frame, no watermark, no UI, no baked health bars.
